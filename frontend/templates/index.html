Algorithmic Behavior Analysis & Theoretical Insights
Why Q-Learning is Aggressive

Q-Learning evaluates policy updates using the maximum potential Q-value $\max_{a'} Q(s', a')$. It assumes the agent will make optimal decisions in the future. As a result, it learns the absolute shortest path even if that path skims right alongside dangerous obstacles.

Why SARSA is Conservative

SARSA evaluates updates using the action $a'$ actually chosen by its behavior policy ($\epsilon$-greedy). Because exploratory mistakes during training result in -10 obstacle penalties, SARSA learns to steer away from obstacles, favoring a slightly longer but much safer path.

Role of the Goal-Based Baseline

Breadth-First Search (BFS) is a classical graph algorithm with access to the environment's full transition matrix and obstacle map. It serves as an upper bound baseline, highlighting what perfect knowledge achieves vs what RL agents learn from scratch.

Reinforcement Learning Foundations & Mathematical Theory

A rigorous academic guide covering the core concepts of Sequential Decision Environments, Temporal Difference learning, Bellman optimality, and mathematical formulations.

1. What is Reinforcement Learning?

Reinforcement Learning (RL) is a paradigm of machine learning where an autonomous learner (the agent) makes sequential decisions within a dynamic environment to maximize a cumulative numerical reward signal. Unlike supervised learning, the agent is never provided correct input-output pairs or explicit supervision; instead, it must discover which actions yield the highest reward through trial-and-error exploration.

2. What is an Agent?

The Agent is the decision-making entity that perceives the state of the environment, executes discrete actions according to a learned policy, receives feedback in the form of rewards, and updates its internal value functions or models to improve future decision-making performance.

3. What is an Environment?

The Environment represents the external world with which the agent interacts. It defines the state space, transition dynamics (physics of motion), boundaries, obstacle constraints, and reward functions. In our implementation, the 2D Grid World functions as a discrete Markov Decision Process (MDP).

4. What is a State?

A State $s \in \mathcal{S}$ represents a complete specification of the agent's current situation within the environment. In the Grid World navigation task, a state is characterized by the agent's discrete coordinate location $(r, c)$, mapped to a discrete state index $s = r \times \text{cols} + c$.

5. What is an Action?

An Action $a \in \mathcal{A}$ is a permissible move chosen by the agent. In our 4-directional Grid World, the discrete action space is:
$\mathcal{A} = \{\text{UP (0)}, \text{DOWN (1)}, \text{LEFT (2)}, \text{RIGHT (3)}\}$.

6. What is a Reward?

The Reward $r_t \in \mathbb{R}$ is the immediate scalar feedback returned by the environment following action $a_t$ taken from state $s_t$:
• Reaching the goal destination: +100.0
• Colliding with an obstacle: -10.0
• Standard movement cost (step penalty): -1.0
• Invalid move (hitting boundary): -5.0

7. Policy & The Exploration vs Exploitation Dilemma
Policy π(a|s)

A Policy $\pi(a|s)$ defines the agent's way of behaving at a given time. It is a mapping from perceived states of the environment to actions to be taken. In value-based methods, the greedy policy selects the action that maximizes the learned state-action value:

$$\pi^*(s) = \arg\max_{a \in \mathcal{A}} Q(s, a)$$
ε-Greedy Exploration Strategy

The fundamental trade-off in reinforcement learning is between exploration (gathering information about uncharted states and actions) and exploitation (using existing knowledge to harvest maximum reward). The $\epsilon$-greedy mechanism balances both:

$$a = \begin{cases} \text{random action from } \mathcal{A} & \text{with probability } \epsilon \\ \arg\max_{a} Q(s, a) & \text{with probability } 1 - \epsilon \end{cases}$$

We apply exponential decay: $\epsilon_{t+1} = \max(\epsilon_{\min}, \epsilon_t \times \text{decay})$, ensuring high initial exploration that progressively gives way to greedy exploitation.

Watkins (1989) • Model-Free Off-Policy
10. Q-Learning Algorithm

Q-Learning is an off-policy Temporal Difference (TD) control algorithm. It updates its Q-table values by assuming that the greedy, optimal action will be chosen in the next state, irrespective of the exploratory policy actually being followed:

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$
Where:
  • $Q(s, a)$: Current state-action value estimate.
  • $\alpha \in (0, 1]$: Learning rate.
  • $r$: Immediate reward received.
  • $\gamma \in [0, 1)$: Discount factor for future rewards.
  • $\max_{a'} Q(s', a')$: Bellman optimality target (best possible Q in next state $s'$).
  • $[r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$: Temporal Difference (TD) Error.
Rummery & Niranjan (1994) • Model-Free On-Policy
11. SARSA Algorithm

SARSA (State-Action-Reward-State-Action) is an on-policy TD control algorithm. Rather than estimating the optimal policy directly, it updates Q-values based on the action $a'$ actually selected by the current behavioral ($\epsilon$-greedy) policy:

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma Q(s', a') - Q(s, a) \right]$$
Where:
  • $Q(s, a)$: Current state-action value.
  • $a'$: Next action chosen from state $s'$ using current $\epsilon$-greedy policy.
  • $Q(s', a')$: On-policy target value.
  • Because $a'$ may be an exploratory action that hits an obstacle, SARSA penalizes states with neighboring hazards during learning.

1. Problem Statement

Autonomous agents operating in sequential decision-making environments face the challenge of reaching target destinations without prior knowledge of the environment's transition dynamics or obstacle locations. Traditional rule-based systems and classical graph-search algorithms require complete, deterministic models of the environment beforehand. In contrast, this project investigates how model-free Reinforcement Learning algorithms can learn optimal navigational policies purely through repeated trial-and-error environmental interactions while balancing the exploration-exploitation dilemma.

2. Project Objectives
  • Implement pure mathematical implementations of Q-Learning (Off-Policy TD) and SARSA (On-Policy TD) without relying on high-level black-box RL libraries.
  • Construct a configurable 2D Grid World navigation environment with user-customizable obstacle layouts, start/goal coordinates, and customizable reward structures.
  • Develop a deterministic Goal-Based Agent baseline using Breadth-First Search (BFS) to provide a theoretical benchmark.
  • Provide interactive real-time training controls with live telemetry (episodes, reward convergence, $\epsilon$ decay, success rates).
  • Deliver interactive visualizations including learned policy direction arrows (↑, ↓, ←, →), state-value heatmaps, and step-by-step path playback.
  • Enable rigorous side-by-side empirical performance evaluations and persist all historical training sessions into an SQLite database.
3. Proposed Methodology & System Architecture

The system is architected as a full-stack, modular web application:

4. Expected Outcomes & Findings

• Convergence: Both Q-Learning and SARSA successfully converge to stable, obstacle-free paths across diverse maze presets within 300–500 episodes.

• Path Variance: Q-Learning consistently converges on the shortest possible path alongside obstacles (identical in length to the BFS baseline), whereas SARSA frequently chooses safer detours with greater clearance around collision zones.

• Exploration Stability: Demonstrating how exponential decay of $\epsilon$ drives initial wide-range map exploration while enabling final deterministic policy exploitation.
